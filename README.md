# Sensor-parser
Конфигурируемый парсер текстовых данных
Требуется разработать программу на C++, которая будет извлекать значения определенных сенсоров из множества текстовых файлов и сравнивать соответствующие сенсоры между собой. Правила извлечения описываются отдельным конфигурационным файлом, который ваша программа должна проанализировать.
В качестве результата работы програмимы, необходимо вывести пользователю в каком файле встретилось максимальное и минимальное значение по каждому правилу и само значение, с учетом преобразования единиц измерений. 

Тип извлекаемых значений: bool, int, float. 
Единицы измерения: абсолютное значение, скорость бит в секунду.

Гарантируется, что формат данных в наборе анализируемых текстовых файлах одинаковый.
Ошибки извлечения данных игнорировать при анализе, но выводить в консоль пользователю.

При решении задачи можно пользоваться сторонними библиотеками для чтения файлов конфигурации, для использования регулярных выражений (если планируется их использовать), для любых других операций, которые не являются решением основной задачи.

При решении задачи, можно писать прикладные скрипты и утилиты на любом языке программирования (например, для наполнения анализируемых файлов).

Поощряется:
- использование ООП
- параллелизация обработки большого количества файлов
- использование docker контейнера с приложенной конфигурацией

Ниже - пример конфигурации и двух файлов, с выводом результата работы анализа 2 файлов.

Пример конфигурации:
```json
{
    'sensors' : [
        { 'name' : 'sensor1', 'rule' : 'Датчик 1' },
        { 'name' : 'sensor2', 'rule' : 'Датчик 2' }
    ],

    'rules' : [
        { 'name' : 'state', 'type' : 'bool',  'rule' : 'Состояние: (.*)', 'true' : 'включен', 'false' : 'выключен' },
        { 'name' : 'temp',  'type' : 'value', 'rule' : 'Температура: (.*)' },
        { 'name' : 'speed', 'type' : 'speed', 'rule' : 'Скорость: (.*) (.*)/s' }
    ],

    'extractors' : [
        { 'sensor' : 'sensor1', 'rules' : [ 'temp', 'speed' ] },
        { 'sensor' : 'sensor2', 'rules' : [ 'state', 'speed' ] }
    ]
}
```

Пример файла:
```text
file1.txt:
    // Показания датчика 1
    Датчик 1: 
        Состояние: включен
        Температура: 36.6
        Скорость: 765 Mbit/s

    // Показания датчика 2
    Датчик 2:
        Состояние: выключен
        Температура: 0
        Скорость: 1.5 Kbit/s
file2.txt:
    // Показания датчика 1
    Датчик 1:
        Состояние: включен
      Температура: 42
        Скорость: 1.4 Gbit/s

   // Показания датчика 2
   Датчик 2:
        Состояние: включен
        Температура: 37
       Скорость: 0 bit/s
```

Вывод к указанному примеру:
```shell
parser /path/to/reports/*.txt

sensor1:
    temp: max=42(file2.txt), min=36.6(file1.txt)
    speed: max=1.4 Gbit/s(file2.txt), min=765 Mbit/s(file1.txt)

sensor2:
    state: max=включен(file2.txt), min=выключен(file1.txt)
    speed: max=1.5 Kbit/s(file1.txt), min=0 bit/s(file2.txt)
```
